# CRISP-DM 線性迴歸 Streamlit 應用

🚀 線上應用程式 (Live App)
[點擊這裡體驗應用程式](https://hw1linearregression-kj46g9dxksknuccz54fo4u.streamlit.app/)

## ✨ 功能

- **互動式參數調整:** 在側邊欄使用滑桿調整數據的 `斜率`、`噪聲等級` 和 `數據點數量`。
- **即時反饋:** 參數一經調整，整個應用的數據、模型和圖表會自動更新。
- **CRISP-DM 流程展示:** 應用程式的介面按照 CRISP-DM 的六個步驟進行組織，並在每個步驟中提供詳細說明。
- **視覺化分析:** 包含數據分佈散點圖和模型擬合結果對比圖。
- **模型評估:** 即時計算並展示模型的均方誤差 (MSE) 和 R-squared (R²) 指標。
- **線上預測:** 提供一個輸入框，讓使用者可以基於訓練好的模型來預測新數據點。

## 🚀 如何執行

**1. 前置要求**

- 已安裝 Python 3.7+ 

**2. 安裝依賴套件**

在您的終端機中，導航到專案根目錄，然後執行以下命令來安裝所有必要的 Python 套件：

```bash
pip install -r requirements.txt
```

**3. 啟動應用程式**

安裝完成後，執行以下命令來啟動 Streamlit 應用程式：

```bash
streamlit run app.py
```

程式執行後，您的預設瀏覽器將會自動打開一個新的分頁，顯示應用程式介面。
